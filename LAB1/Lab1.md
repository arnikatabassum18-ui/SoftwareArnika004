# **Experiment Name: -**
Basic documentation using Markdown language.

## **Objectives**
1. To understand the basic syntax of Markdown language.
2. To create structured documents using headings, lists, and tables.
3. To format text using bold, italic, blockquotes, and code blocks.
4. To insert hyperlinks, images, and other documentation elements.

## **Theory**
Markdown is a lightweight markup language used to create well-structured and readable documents with simple text formatting syntax. It allows users to add headings, lists, tables, links, images, and code blocks without using complex HTML tags. Markdown is widely used for software documentation, README files, blogs, and technical reports because it is easy to learn and portable across different platforms.
## **Code**
